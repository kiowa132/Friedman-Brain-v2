# Friday Blog Article — Standing Procedure

This file documents Kyle Friedman's Friday content piece workflow: a buyer-
or seller-focused deep-dive article, distributed to Substack and the
website, with supporting image prompts and a video script. This runs as
**two separate processes** — a monthly batch session and a weekly pull —
so Kyle is never researching/writing same-day under deadline pressure.

## What each finished piece is — 3 deliverables
1. **A written article** (buyer- or seller-focused educational deep-dive)
   for Substack and the website SEO article
2. **4 detailed image prompts** for use in ChatGPT/DALL-E/Midjourney
3. **A 15–20 second social video script** — story/hook-driven, NOT Kyle
   reciting data to camera. Needs a hook, a turn/twist, and a short payoff.
   Format as a time-coded table (time / visual+edit direction / audio or
   on-screen text).

## Process A — Monthly batch session (do this ~once a month, or whenever
the queue runs low)
1. Read `friday-blog-article-log.md` (published) and
   `friday-blog-article-queue.md` (already queued) — never propose a topic
   in either.
2. Propose **~4 new topic candidates** to Kyle first — don't research and
   write on spec. Favor topics reinforcing brand positioning (see
   `../notes/brand-guidelines.md`), especially the farm/equestrian niche,
   over generic national content.
3. Once Kyle approves topics, for each one: research it (web search —
   don't state Maryland-specific legal/tax/financing facts from memory
   alone), write the full article, write the 4 image prompts, write the
   video script.
4. Save each finished set to `../drafts/friday-articles/<date>-<slug>/`
   as `article.md`, `image-prompts.md`, `video-script.md`.
5. Add each to `friday-blog-article-queue.md` under "Ready," tagged with
   its target Friday date.

## Process B — Weekly Thursday pull (fast — no research, just retrieval)
1. By **Thursday**, not Friday: check `friday-blog-article-queue.md` for
   the item ready for the nearest Friday.
2. Surface it to Kyle for final review — this gives him Thursday–Friday
   to actually schedule the video and blog post, instead of scrambling
   Friday morning.
3. If nothing is "ready" for the upcoming Friday, flag this to Kyle
   immediately rather than rushing a same-day piece — that's the signal
   the queue needs refilling (Process A).
4. Once Kyle publishes it, move the topic from the queue file to
   `friday-blog-article-log.md` and delete its queue entry.

## Standing build rules
- Branding & tone: follow `../notes/brand-guidelines.md` — don't duplicate
  those rules here, check there.
- Never generate Kyle's actual face via AI image tools — text-to-image
  tools can't reliably reproduce a specific real person anyway. If Kyle
  wants himself in a graphic: use a real photo + add text/graphics in
  Canva, not AI generation.
- Don't rely on AI tools for legible on-image text — recommend adding text
  as a post-process step (Canva) instead.
