# Accounts & Credentials

Local credential store for Kyle's business tools. **Plain text, not
encrypted** — protected only by normal file access on this machine (a
deliberate tradeoff Kyle chose 2026-09-14: simple and easy to maintain
over an encrypted vault that needs a master password). This vault is not
a git repository (confirmed 2026-09-14), so this file stays local only,
never pushed anywhere.

## How to add a new entry
Copy this block, fill it in, drop it under the alphabetized list below.
Leave any field blank/omit it if not applicable, don't invent placeholder
values.

```
## <Service Name>
- **Username/Email:**
- **Password:** (or "see password manager" if kept elsewhere)
- **2FA / Recovery code:**
- **Notes:**
- Saved/updated: YYYY-MM-DD
```
