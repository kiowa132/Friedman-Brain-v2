# brand-assets/

Reusable reference images for the image pipeline (`scripts/gen-image.ps1`).
Drop these here once; they get reused as references on every report.

| File | What | Used for |
|---|---|---|
| `headshot.jpg` | Kyle's professional headshot, clean background | "with Kyle" slots (still hit-or-miss on free tier) |
| `logo.png` | The Friedman Team wordmark, **transparent PNG** | every branded graphic — tool reproduces it |
| `swatch.png` | swatch of the 5 brand hex values (`#0F5C63` teal, `#C9A96A` gold, `#FAF8F5` cream, `#0D2226` ink, `#B5544A` loss-red) | color grading |
| `look-1.jpg` … `look-5.jpg` | 3–5 example images in the visual style Kyle wants (editorial real-estate photography, restrained/premium) | style steering |
| `guide.jpg` | phone photo of a printed Friedman Team buyer/seller guide | matching printed-collateral looks |

Keep references ~1024px on the long edge — smaller files = faster, cheaper
(free-tier) generations. `.jpg`, `.png`, or `.webp`.
