# Image Prompts — Friedman Report, Week of August 24–30, 2026

Format: 4 banner images, **16:9 (crops cleanly to 3:1)**. Baked-in text is
wanted — exact copy is specified per image; tell the tool spelling must be
correct and text must be sharp. Feed the listed reference assets into the
tool so nothing looks like generic stock.

**Force the aspect ratio with the tool's control, not the prompt text —
tools ignore "16:9" written in a sentence:**
- ChatGPT / DALL·E: instruct it "wide 16:9 landscape, 1792×1024,
  horizontal"; if it returns vertical, reply "regenerate wider, landscape
  not portrait".
- Midjourney: append `--ar 16:9`.
- Ideogram / Leonardo / Firefly: select the 16:9 / Landscape box first.
- Most reliable anywhere: upload a blank 1920×1080 canvas as a reference
  image and say "match this canvas's dimensions".

**Brand palette to cite in every prompt:** deep teal `#0F5C63`, warm gold
`#C9A96A`, cream `#FAF8F5`, near-black ink `#0D2226`, loss-red `#B5544A`.
Editorial real-estate / finance photography, restrained and premium. The
negative list must forbid the string "REAL ESTATE" anywhere in the image —
tools keep inventing a "FRIEDMAN REAL ESTATE TEAM" logo, which violates the
naming rule. Upload the real transparent LOGO every time.

**Reference assets to upload (have these ready):**
- `HEADSHOT` — Kyle's professional headshot (for image 4)
- `SITE` — 1–2 screenshots of a current friedmanreteam.com market report
  post + the stat-tile grid (match type, spacing, card style)
- `LOGO` — The Friedman Team wordmark / logo, transparent PNG
- `SWATCH` — a swatch image of the five brand hex values above
- `GUIDE` — a phone photo of one of your printed buyer guides / collateral
  (optional for image 4)
